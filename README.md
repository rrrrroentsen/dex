# 相遇图鉴（Encounter Dex）

把日常里遇到的宝可梦——玩偶、手办、卡牌、包装上的图案——拍下来，手机自己认是哪一只，收进自己的图鉴，看多久能集齐 1025 种。

版本 1.1.0 · 图鉴数据到第九世代（No.0001–No.1025），另有 262 个特殊形态（Mega、地区形态、超极巨化等）可以单独记录。

这是爱好者自己做的非官方工具，和任天堂、Creatures、GAME FREAK、宝可梦公司没有关系。

## 它是怎么工作的

- 一个放在 GitHub Pages 上的网页，添加到 iPhone 主屏幕以后像 App 一样用。
- 界面是一台掌上机器的样子：黄色的机身，中间一块带扫描线的屏幕，屏幕下面一排按键。所有页面都显示在这块屏幕里，主要的操作在按键上。
- **识别在手机上完成**：识别模型第一次打开时下载一次（约 35 MB），之后存在手机里。照片不上传到任何地方，不需要申请 key，不花钱，没有次数限制，没网也能认。需要 iOS 16.4 或更新的系统。
- 记录和照片只存在这台手机的这个 App 里。换手机或者想留底，用「设置 → 保存备份文件」。
- 图鉴里每只的参考小图在联网时从 PokeAPI 的公开图库加载，没有打包在这个工具里；看过的会留在手机上，没网时也能显示。

## 部署到 GitHub Pages

和前几个工具一样的做法，大约五分钟。

1. 在 GitHub 上新建一个公开仓库，名字建议叫 `dex`。
2. 进仓库，点 **Add file → Upload files**，把压缩包解开后 `dex` 文件夹**里面的全部文件**（不是文件夹本身）一起拖进去，等全部传完，点 **Commit changes**。
   - 一共 23 个文件，都在同一层，没有子文件夹。
   - 最大的一个是识别模型 `recog-model-1.onnx`（约 24 MB，网页上传的上限是 25 MB，没有超）。它和 `ort-wasm-simd-1.18.0.wasm`（约 11 MB）传得慢一些，等进度条走完再提交。
3. 仓库的 **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选 **main** 和 **/(root)**，点 Save。
4. 等一两分钟，打开 `https://rrrrroentsen.github.io/dex/`（把 `dex` 换成你实际的仓库名）。

这个地址和飞行图、家务打卡、我的装备、足迹地图在同一个域名下。它只用自己名字开头的存储（`encdex`），不会碰另外几个工具的数据。

## 装到 iPhone 主屏幕

1. 用 **Safari** 打开上面的地址（微信里打开的话，先点右上角选「在 Safari 中打开」）。
2. 点底部的分享按钮 → **添加到主屏幕**。不用等 Safari 里的「正在准备识别模型」走完：主屏幕上的 App 有自己单独的存储，会自己再下载一次。
3. 从主屏幕打开。第一次打开时保持联网，首页会显示「正在准备识别模型」，等它下载完（Wi-Fi 下一般不到一分钟）。
4. 按屏幕下面中间的大圆键「扫描」。第一次会问能不能用摄像头，选允许。

请只用主屏幕上的 App 来记录：在 Safari 里直接打开的网页，如果连着几天不访问，Safari 有可能自动清掉它存的数据；添加到主屏幕的 App 不受这条限制。

主屏幕上的 App 和 Safari 里打开的网页，存储是分开的。如果先在 Safari 里试用并且存了记录，想搬到主屏幕 App 里：在 Safari 里「设置 → 保存备份文件」，再到主屏幕 App 里「设置 → 从备份文件恢复」。

## 第一次用，请留意这几件事

这一版只在电脑上模拟 iPhone 测过，没有在真机上跑过。下面几件事拿不准，第一次用的时候看一眼：

1. 首页的「正在准备识别模型」能不能走完。走完以后，机身右上角小窗里的灯变成绿色常亮，扫描时左上角显示「识别已就绪」。
2. 取景器有没有画面。没有的话点「用系统相机拍」。
3. 拍一张，从按下快门到出候选要多久（估计一秒左右）。
4. 「设置 → 保存备份文件」能不能把 zip 存进「文件」。记录多了以后这是唯一的留底办法，建议一开始就试一次。

哪一步不对，先看下面的「常见问题」。

## 怎么用

1. **扫**：按大圆键「扫描」，把它放进取景框里，拍大一点、正一点，再按一次大圆键拍下来。远处的东西可以点屏幕上的「2×」。左边的「相册」键可以选一张以前拍的。
2. **认**：一条亮线扫过照片，然后屏幕上给出最像的一只，下面还有几个候选。点对的那一只。都不对就按大圆键「搜名字」（中文名、英文名、拼音、拼音首字母、编号都行，比如「皮卡丘」「pikachu」「pkq」「25」）。
3. **记**：可以选它是什么（玩偶、手办、卡牌……）、在哪里遇见的、写一句笔记，然后按大圆键「收进图鉴」。这些都可以不填。

### 机器上的东西

- **机身右上角的小窗**：一盏灯和一个数。灯是识别模型的状态：绿色常亮是就绪，黄色闪烁是正在准备，红色是出了问题（首页会说是什么问题），不亮是关掉了自动识别。数是已经收集到的种类。
- **屏幕下面的五个键**：首页、我的（图鉴）、扫描、全国（图鉴）、设置。正在看的那一页，键上的小灯会亮。
- **扫描的时候**，下面换成三个键，中间的大圆键永远是「下一步」：拍照 → 搜名字或者收进图鉴 → 继续拍。左右两个键是旁边的选择（相册、系统相机、重拍、换一只、完成、看看它）。上面左边的键是关闭，右边的键切换前后摄像头。
- **屏幕的颜色**：「设置 → 屏幕」可以选深色（夜里用）、浅色（白天用）或者跟随系统。机身不变。

在「全国」里点任何一只，可以看它的资料和你拍过的照片；已经知道是哪一只的时候，从它的页面点「遇到了，拍下来」，就不用再认一遍。

首页会按你最近的速度估算哪天能集齐（要先记录满一周）。

## 识别有多准

识别模型是为这个工具单独做的：用一个公开的通用图像模型，加上用 1287 种宝可梦和形态的参考图训练出来的分类层。

我在开发环境里能做的测试和结果（手机上用的是同一个模型、同一套算法）：

| 测试 | 第一个就猜对 | 对的在六个候选里 |
| --- | --- | --- |
| 模拟拍照 600 张：把参考图放进各种日常照片背景里，随机大小、角度、亮度、模糊、遮挡 | 88% | 96% |
| 颜色不对的同一只 400 张：用训练时没见过的异色版本 | 73% | 87% |
| 换成训练时没见过的画风或造型（每次留出一种，只认一遍、不做多次取景） | 约 50%–75% | 前五名约 70%–85% |

模拟拍照里，手机「有把握」的占七成左右（这时会直接给出一只让你确认），这部分几乎全对；剩下的会列出候选让你挑。

**没有测过的是真实的玩偶和手办照片**：开发环境里拿不到这类照片。实际准确率估计比上面的数字低，造型和官方图差得越远的周边越容易认错。所以识别结果是「候选」，最后由你点一下确认。

几点实际使用的建议：

- 拍的时候让它占满取景框的大半，尽量拍正面。
- 给出的候选是「最像的几只」，同一进化链的经常排在一起，点对的那只就行。
- **越用越准**：你确认过的每张照片都会留作参考。同一个玩偶、同一款周边再拍到时，会直接排在第一个。
- 实在认不出来就手动搜，一样能收进图鉴。「我的图鉴 → 统计」里有一栏「识别成绩」，可以看到实际认对了多少。

## 备份和换手机

- 「设置 → 保存备份文件」会把所有记录和照片打包成一个 zip，可以存到「文件」、网盘，或者隔空投送到电脑。它是普通的 zip，照片在里面的 `photos` 文件夹里，可以直接看。
- 「设置 → 从备份文件恢复」选这个 zip。可以「合并进来」（只添加这台设备上没有的）或者「换成备份里的」。
- 建议隔一段时间存一份。删除主屏幕上的 App 图标、或者在系统设置里清除网站数据，会把记录一起删掉。

## 升级

有新版本时，把新的文件全部上传到同一个仓库覆盖旧的就行（文件名都一样），记录、照片和设置不受影响。识别模型的文件名里带版本号：模型没换就不会重新下载，换了手机会自动下载新的。

- 传完以后等几分钟，把主屏幕上的 App 关掉再打开（要联网）。刚传完的十分钟里，手机上可能还是旧的样子：GitHub Pages 让浏览器把文件留十分钟。过一会儿再打开就是新的。
- 主屏幕上的图标不会跟着换：iPhone 只在「添加到主屏幕」的时候取一次图标。想换成新图标，要把旧图标删掉再重新添加，而删图标会把记录一起删掉，所以一定先「保存备份文件」，重新添加以后再「从备份文件恢复」。不换图标不影响使用。

第十世代的宝可梦正式公布全国图鉴编号以后，需要更新 `dex.js`（图鉴数据）和识别模型。在那之前，1025 就是全部。

## 常见问题

**取景器是黑的。**
iPhone 的主屏幕 App 有时候打不开网页里的摄像头（等五秒没有画面，屏幕上会出现提示）。点提示里的「用系统相机拍」，或者按右边的「系统相机」键；也可以到「设置」里打开「用系统相机拍」，之后就一直用系统相机，拍完回来裁一下再识别。

**取景器里很糊，对不上焦。**
网页里的取景器只能用主摄像头，离得太近（十几厘米以内）对不上焦，卡牌、挂件这类小东西尤其明显。离远一点（20 厘米以上），再点「2×」放大；或者用系统相机拍，它会自己换微距镜头。

**每次打开都问能不能用摄像头。**
这是 iPhone 对主屏幕网页 App 的做法，目前关不掉：每次重新打开 App，或者摄像头停了一分钟以上再用，系统都会再问一次。嫌麻烦的话，到「设置」里打开「用系统相机拍」：改用 iPhone 自带的相机界面拍，不会问权限，对焦和变焦也更好用，只是拍完要多点一下「使用照片」，再裁一下。

**横着拿手机，机器变得又矮又宽。**
这台机器是按竖着拿设计的。横过来也能用，取景器会缩小到整个都看得见，只是屏幕很矮。拍东西的时候手机容易跟着转，可以在 iPhone 的控制中心里打开「竖排方向锁定」。

**填完地点或笔记，键盘挡住了下面的按键。**
地点那一栏：按键盘右下角的「完成」，键盘会收起来。笔记那一栏可以换行，回车不会收起键盘：点一下键盘外面的地方（不是输入框），键盘就收起来了，「收进图鉴」那个大圆键也就露出来了。

**首页一直显示「正在准备识别模型」，或者说没能启动。**
先确认联网，然后在首页那张提示卡上点「再试一次」（按「扫描」键时也会自动再试）。还不行，就到「设置 → 识别模型」点「重新下载」。如果是刚上传完文件，等一两分钟让 GitHub 发布完再试。模型没准备好的时候，照样可以拍照、手动搜名字收进图鉴。

**提示「这台设备不能在手机上识别」。**
识别要用到 iOS 16.4 才有的功能（WebAssembly SIMD），更旧的系统跑不了；打开了系统的「锁定模式」也不行。拍照、手动搜名字、图鉴、备份都不受影响。

**首页提示「识别模型的自检没有通过」。**
每次启动识别模型，它都会先认一张内置的测试图，把结果和标准答案比一下（正常是 1.00）。没通过说明这台手机算出来的数不对，候选会不准；这不是你拍得不好。把提示里的那句话（带相似度数字）记下来反馈，这段时间先手动搜名字。

**拍完一直停在「正在认是哪一只」。**
等到 30 秒还没有结果，它会自己停下来，让你手动选。下次按「扫描」键时识别模型会重新启动。如果每次都这样，到「设置 → 识别模型」点「重新下载」。

**图鉴里的小图不显示，是一个问号。**
参考图要联网从 PokeAPI 的图库加载。没网、或者那边暂时打不开时就显示问号，不影响记录。也可以在「设置」里关掉参考图。

**认错了，已经存进去了。**
点那条记录 →「修改」，搜对的名字换掉。

**想改名字或者图标。**
名字在 `manifest.webmanifest` 的 `name`、`short_name` 和 `index.html` 的标题里；图标是几个 `icon-*.png`。改完重新上传，再把主屏幕上的图标删掉重新添加（先备份）。
