2. Recognition model (recog-model-1.onnx, recog-head-1.bin)
-----------------------------------------------------------
recog-model-1.onnx is the feature-extraction part of the "SWSL ResNet-50" image model
released by Facebook Research in the repository
https://github.com/facebookresearch/semi-supervised-ImageNet1K-models
described in: I. Z. Yalniz, H. Jegou, K. Chen, M. Paluri, D. Mahajan,
"Billion-scale semi-supervised learning for image classification", arXiv:1905.00546.

  The model weights are licensed under Creative Commons Attribution-NonCommercial 4.0
  International (CC BY-NC 4.0): https://creativecommons.org/licenses/by-nc/4.0/
  NON-COMMERCIAL USE ONLY.

Changes made for this tool: the ONNX export published in the ONNX Model Zoo
(https://github.com/onnx/models, exported with the timm library) was cut before its
classification layer, weights too small to matter were set to zero, and the weights were
converted to 8-bit integers.

recog-head-1.bin (the layer that turns image features into species scores) was trained for
this tool from feature vectors of reference pictures; it contains no pictures.
